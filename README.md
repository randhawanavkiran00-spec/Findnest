# college-lost-and-found-management-system
FindNest – College Lost and Found Management System

FindNest is a simple, menu-driven C programming project designed to help college students manage lost and found items.

It allows users to report lost or found belongings, view records, search for items, identify possible matches, and update the status of returned items.

Features

- Report lost and found items.
- View all lost and found records.
- Search for specific items.
- Match lost items with found items.
- Mark items as returned.
- Store records using file handling.

Technologies Used

- C Programming
- Structures
- Arrays
- Functions
- Pointers
- Strings
- File Handling

Objective

To provide a simple and organised system that helps students recover their lost belongings within the college campus.
